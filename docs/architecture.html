DownVid Architecture

Electron + Vue 3 multi-platform video downloader · Go dependency sidecar + yt-dlp

Main Process

  • • Electron main.ts — window, lifecycle, logging
  • • IPC handlers: download, history, app, system, deps
  • • Parser dispatch: Douyin → Kuaishou → yt-dlp
  • • Runtime deps via Go sidecar: system PATH → managed dir → manual
  • • Direct fetch (CDN) or spawn yt-dlp subprocess
  • • Pause = kill process, resume = re-spawn from .part

Renderer Process

  • • Vue 3 + Tailwind + Pinia, no router
  • • v-show tab switching: Download / History / About
  • • Settings as floating panel, not a route
  • • State: localStorage settings (not Pinia)
  • • Progress via IPC broadcast, throttled 200ms
  • • DepPanel (settings) + DepsPrompt (missing deps) via deps:* IPC

Download Flow

  • • Parse URL → extract formats / direct CDN URL
  • • Douyin/Kuaishou: API first, Puppeteer fallback
  • • Direct URL → fetch + write stream
  • • Otherwise → spawn yt-dlp with format selector
  • • Audio: -x mp3 · Subs: --write-subs · Merge: ffmpeg
  • • Deps resolved by sidecar (no bundled binaries); missing → one-click download
