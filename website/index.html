常见问题

更多问题见仓库文档。

提示缺少 yt-dlp 或 FFmpeg？

安装包不内置这两个工具。应用会先找系统里已有的版本；找不到时按提示下载，或到「设置 → 运行依赖」里管理。

macOS 提示无法验证开发者？

首次打开时右键点击应用选择「打开」，或到「系统设置 → 隐私与安全性」中允许。应用没有付费开发者证书，这是已知取舍。

有些视频下载失败？

多数情况是该网站需要登录。请确认你有权访问该内容，然后在设置里读取浏览器登录状态或导入 cookies.txt。网站改版也会影响解析成功率。
