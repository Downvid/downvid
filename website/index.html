前往下载 安装指南

提示：macOS 上应用未做代码签名，首次打开需要在「系统设置 → 隐私与安全性」中允许。

安装与运行

每个平台的安装方式略有不同，这里是最常见的几步。

macOS：应用未签名

首次打开需在「系统设置 → 隐私与安全性」中允许；也可以先去掉隔离属性。

xattr -cr /Applications/DownVid.app

Linux：AppImage 免安装

下载后加执行权限直接运行；deb / rpm 交给包管理器。

chmod +x DownVid-*.AppImage && ./DownVid-*.AppImage

从源码构建

需要 Node 22+ 与 pnpm；Go 边车会在启动时自动编译。

pnpm install && pnpm dev

常见问题

更多问题见仓库文档。

提示缺少 yt-dlp 或 FFmpeg？

安装包不内置这两个工具。应用会先找系统里已有的版本；找不到时按提示下载，或到「设置 → 运行依赖」里管理。

macOS 提示无法验证开发者？

首次打开时右键点击应用选择「打开」，或到「系统设置 → 隐私与安全性」中允许。应用没有付费开发者证书，这是已知取舍。

有些视频下载失败？

多数情况是该网站需要登录。请确认你有权访问该内容，然后在设置里读取浏览器登录状态或导入 cookies.txt。网站改版也会影响解析成功率。

会下载版权内容吗？

DownVid 只是 yt-dlp 的图形界面，不含任何破解或绕过技术保护措施的代码。请遵守当地法律、平台规则与内容版权，使用后果由使用者承担。
