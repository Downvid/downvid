我是 Black Cat，DownVid 的作者。

做这个工具的原因很朴素：有些视频我想留在本地——可能是旅行时看过的一段风景，也可能是一个随时会消失的教程。平台会下架、会限流、会要求登录，但已经下载到硬盘上的文件不会。

所以 DownVid 尽量把解析、下载、合并、字幕都放在你自己的机器上完成，也不内置 yt-dlp / ffmpeg，而是优先用你系统里已经有的版本。它不完美，但方向是「你的文件，你做主」。

## 我尽量坚持的几件事

- 解析和下载都在本机完成，不经过第三方服务器
- 优先使用系统里已有的 yt-dlp / ffmpeg，而不是塞一份进安装包
- 更新通道保留多条降级路径，不让某一条路断掉就永远收不到新版本

如果它帮到了你，欢迎在 GitHub 点个 Star，或者请我喝杯咖啡；遇到问题请直接提 Issue，带上日志，我会看。

谢谢你把 DownVid 留在桌面上。
